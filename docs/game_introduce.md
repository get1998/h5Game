## 五、五行属性伤害（附加于攻击/法术）

### 5.1 五行基础属性

| 属性名称 | 说明 | 数值范围（初期） |
| --- | --- | --- |
| 金系攻击 | 对木系目标伤害加成 | 0 ~ 200 |
| 木系攻击 | 对土系目标伤害加成 | 0 ~ 200 |
| 水系攻击 | 对火系目标伤害加成 | 0 ~ 200 |
| 火系攻击 | 对金系目标伤害加成 | 0 ~ 200 |
| 土系攻击 | 对水系目标伤害加成 | 0 ~ 200 |
| 对应抗性 | 金/木/水/火/土抗性，减免对应属性伤害 | 0% ~ 50% |

### 5.2 五行相克关系（伤害加成系数）

| 攻击属性 | 克制属性 | 伤害系数 | 被克制属性 | 伤害系数 |
| --- | --- | --- | --- | --- |
| 金 | 木 | 1.5倍 | 火 | 0.8倍 |
| 木 | 土 | 1.5倍 | 金 | 0.8倍 |
| 水 | 火 | 1.5倍 | 土 | 0.8倍 |
| 火 | 金 | 1.5倍 | 水 | 0.8倍 |
| 土 | 水 | 1.5倍 | 木 | 0.8倍 |

额外规则：若攻击方同时拥有多种五行属性，则分别计算各自伤害，最后相加。

### 5.3 最终五行伤害计算公式

单属性伤害 = 该系攻击力 × 技能五行倍率 × (克制系数 - 对方抗性系数)  
总伤害 = 基础物理伤害 + 各系五行伤害

## 六、经验值（境界经验）系统

### 6.1 经验值与境界的关系

经验值 = 境界经验条，填满后突破至下一境界。升级难度很高，每提升一个大境界，所需经验值翻倍甚至更高。

| 境界 | 升级所需经验（累计） | 典型怪物掉落经验（同境界） |
| --- | --- | --- |
| 炼气期 | 0 → 1000 | 10~30 |
| 筑基期 | 1000 → 5000 | 50~150 |
| 金丹期 | 5000 → 20000 | 200~500 |
| 元婴期 | 20000 → 100000 | 800~2000 |

### 6.2 经验值获取公式

获得经验 = 怪物基础经验 × 功法经验倍率

怪物基础经验：由怪物自身境界固定，同境界怪物经验值相同。  
功法经验倍率：当前装备的主修功法提供的倍率（例如1.0倍、1.5倍、2.0倍等）。

示例：击杀筑基期怪物（固定经验100），装备“玄天功法”（倍率1.8倍），则获得180经验。

### 6.3 经验值分配限制

若玩家境界远高于怪物（如金丹期打炼气期），可设定最低保底经验（如1点），防止无限刷低级怪。建议加入“每日经验上限”或“境界压制减益”，鼓励挑战同级或高阶怪物。

## 七、功法系统

### 7.1 功法基础属性

| 属性 | 说明 | 示例 |
| --- | --- | --- |
| 功法名称 | 功法唯一标识 | 《太古造化诀》 |
| 功法等级 | 影响解锁技能数量、效果强度 | 1~10级（或入门→小成→大成→圆满） |
| 功法经验值 | 当前等级下积累的经验，满则升阶 | 0~1000 |
| 功法经验倍率 | 打怪时额外乘算的经验倍率 | 1.2倍/1.5倍/2.0倍 |
| 技能列表 | 从该功法中领悟的技能（主动/被动） | 御剑术、三昧真火、遁术… |
| 灵根适配 | 不同灵根修炼该功法的速度加成 | 火灵根修炼火系功法速度+50% |

### 7.2 功法等级与技能获取规则

功法每升1级，解锁1个新技能（或强化已有技能）。技能只能通过装备该功法并使用来获得熟练度，不可脱离功法单独升级。

| 功法等级 | 解锁技能数量 | 技能强度倍率 |
| --- | --- | --- |
| 1级 | 1个基础技能 | 1.0倍 |
| 2级 | 2个技能 | 1.1倍 |
| 3级 | 3个技能 | 1.2倍 |
| ... | ... | ... |
| 10级（圆满） | 10个技能（含终极技） | 2.0倍 |

### 7.3 功法升级条件（经验获取）—— 明面效果 + 隐藏效果

完整公式：  
功法经验增量 = 怪物境界固定经验 × 灵根适配倍率（明） × 五行相生相克系数（隐）

**（明）灵根适配倍率**

| 灵根类型 | 倍率 | 说明 |
| --- | --- | --- |
| 单灵根（适配功法属性） | 1.5倍 | 如：火灵根修炼火系功法 |
| 双灵根（其中一属性适配） | 1.2倍 | 如：[金,水]灵根修炼水系功法 |
| 杂灵根（无适配属性） | 0.8倍 | 任何功法都较慢 |

**（隐）五行相生相克系数**（后台计算，不直接显示）

| 灵根属性 vs 功法属性关系 | 隐藏系数 | 示例 |
| --- | --- | --- |
| 相同 | 1.5倍 | 火灵根 + 火系功法 |
| 相生（灵根生功法 或 功生灵根） | 1.2倍 | 木灵根 + 火系功法（木生火）；火灵根 + 土系功法（火生土） |
| 相克（灵根克功法 或 功法克灵根） | 0.5倍 | 火灵根 + 水系功法（水克火）；金灵根 + 木系功法（金克木） |

隐藏效果叠加示例：  
- 火灵根（单灵根）修炼火系功法 → 明倍率1.5 × 隐系数1.5 = 2.25倍  
- 火灵根（单灵根）修炼土系功法（火生土，相生） → 明倍率1.5 × 隐系数1.2 = 1.8倍  
- 火灵根（单灵根）修炼水系功法（水克火，相克） → 明倍率1.5 × 隐系数0.5 = 0.75倍

**怪物境界固定经验表**

| 怪物境界 | 功法经验 |
| --- | --- |
| 炼气期 | 1 |
| 筑基期 | 3 |
| 金丹期 | 10 |
| 元婴期 | 30 |
| 化神期 | 100 |

最终功法经验 = 上表数值 × 明倍率 × 隐系数（结果向下取整）

### 7.4 功法满级后

功法满级后不再获得功法经验，可更换其他功法继续修炼。

## 八、战斗计算公式参考

### 8.1 最终伤害

最终伤害 = 攻击力 × 技能倍率 × (暴击？暴击伤害 : 1) × 随机波动(0.9~1.1) - 目标防御力 × (1 - 穿透/100)

### 8.2 五行伤害（已包含在总伤害中）

单属性伤害 = 该系攻击力 × 技能五行倍率 × (克制系数 - 对方抗性系数)  
总伤害 = 基础物理伤害 + 各系五行伤害

### 8.3 命中判定

最终命中率 = 基础命中率 + (己方速度 - 敌方速度) × 0.1%  
（最终命中率不低于20%，不高于100%）
