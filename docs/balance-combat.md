# 莽荒大陆 · 战斗数值设计说明

## 一、世界观与战斗前提

**莽荒大陆**：灵气暴烈、秩序粗粝，野外以**妖兽**为绝对多数；开启灵智的**灵兽**极少；散修、盗匪等**人形修士**占比较低。

本阶段数值前提（当前版本）：

| 前提 | 说明 |
|------|------|
| 无功法器 | 玩家无法器 flat / 被动加成，不算法器品阶 |
| 默认构筑 | 单灵根与入门凡品功法**属性匹配**（最佳默认新手态） |
| 同级对比 | 玩家境界与怪物境界相同（如均为「炼气三层」） |
| 品阶 | 对比以**普通**怪为准；精英 / 首领 / 传奇另乘品阶系数 |

**设计目标（最低默认）**：

| 怪物种类 | 同级结果 | 玩家需高出约 |
|----------|----------|--------------|
| 人形修士 | 略占上风或互有胜负 | 0 级（同境可打） |
| 妖兽 | 明显劣势 | **3** 个小境界 / 炼气层 |
| 灵兽 | 极难抗衡 | **5** 个小境界 / 炼气层 |

> 例：炼气一层普通妖兽，炼气四层同构筑玩家方可稳赢；炼气一层普通灵兽，需炼气六层左右。

## 二、玩家战斗属性链路

### 2.1 境界基础（突破时写入 `player.combat`）

```
整数属性 = floor(境界表 × 突破战斗倍率)
突破战斗倍率 = 功法品阶(expMultiplier) × 突破灵根系数 × 突破五行系数
```

- 突破灵根 / 五行系数：`src/game/constants/breakthrough.ts` → `BREAKTHROUGH_STAT_*`
- **与闭关、功法经验分离**：闭关仍用 `SPIRIT_ROOT_ADAPT_MULTIPLIER`、`ELEMENT_HIDDEN_MULTIPLIER`（1.5 / 1.2 / 0.8 等）

### 2.2 有效战斗（历练 / 界面展示）

```
有效属性 = 境界基础 + 主修功法 flat + 永久被动 + 称号 + 轮回
```

暴击 / 命中 / 闪避：境界表 ± 贡献者 flat；**不吃**突破倍率。

### 2.3 校验用默认构筑（`COMBAT_BALANCE_BASELINE`）

| 项 | 值 |
|----|-----|
| 灵根 | 单灵根，与功法同属性 |
| 功法 | 凡品，1 级（如《赤焰诀》） |
| 法器 | 无 |
| 突破战斗倍率 | 约 **1.32**（1 × 1.15 × 1.15） |

## 三、怪物战斗属性链路

### 3.1 人形修士（独立链路）

对齐玩家：**突破缩放境界底 + 功法 flat**，强度由模拟灵根与功法等级体现，品阶仅轻量放大。

```
① realmScaled = floor(境界表 × 模拟突破倍率)     // calcRealmBreakthroughStatMultiplier
② withGongfa  = realmScaled + 功法flat            // 功法等级随品阶/境界
③ 面板        = floor(② × 人形品阶轻量系数) + 五行/个体修正
```

| 品阶 | 模拟灵根 | 功法等级（炼气一层例） | 整数品阶系数 |
|------|---------|----------------------|-------------|
| 普通 | 杂灵根 | 1 | 1.0 |
| 精英 | 双灵根 | 1 | 1.05 |
| 首领 | 单灵根 | 2 | 1.1 |
| 传奇 | 单灵根 | 4 | 1.15 |

配置：`combat-balance.ts`（`HUMAN_MONSTER_*`）、`human-monster-combat.ts`

### 3.2 妖兽 / 灵兽

```
战斗属性 = floor(境界裸表 × 种类系数 × 品阶系数) + 模板修正
```

| 种类 | 种类系数 | 遇怪权重（莽荒默认） | 说明 |
|------|---------|---------------------|------|
| 妖兽 | **1.75** | **1.0**（主） | 同级需玩家高约 3 级 |
| 灵兽 | **2.2** | **0.04**（稀少） | 同级需玩家高约 5 级 |

### 3.3 妖兽品阶系数

| 品阶 | 整数属性 | 比率属性 |
|------|---------|---------|
| 普通 | 1.0 | 1.0 |
| 精英 | 1.3 | 1.15 |
| 首领 | 1.6 | 1.3 |
| 传奇 | 2.0 | 1.5 |

配置入口：

- 妖兽 / 灵兽种类系数：`MONSTER_REALM_COEFFICIENT_BY_KIND`
- 境界差目标：`COMBAT_BALANCE_REALM_GAP`（`human: 0`，`beast: 3`，`spiritBeast: 5`）
- 遇怪权重：`MANGHUANG_MONSTER_KIND_WEIGHTS`；各地图见 `maps.ts`

## 四、炼气期校准表（普通怪 · 默认构筑）

境界裸表 + 玩家突破 1.32 + 凡品攻 +7（赤焰诀）；妖兽 / 灵兽无功法 flat。

### 炼气一层怪物 vs 玩家（默认构筑）

| 对象 | 气血 | 攻击 | 同级玩家结果 |
|------|------|------|-------------|
| 人形普通 + 锐金诀 | ~264 | ~34 | 玩家有效约 **40** 攻，**略优** |
| 人形精英 + 锐金诀 | ~277 | ~40 | **五五开 ~ 略劣** |
| 妖兽普通 | 437 | 43 | **明显劣势** |
| 灵兽普通 | 550 | 55 | **极难** |

### 境界差验证（打炼气一层普通怪）

| 玩家境界 | vs 人形一层 | vs 妖兽一层 | vs 灵兽一层 |
|----------|------------|------------|------------|
| 炼气一层 | 可打 | 打不过 | 打不过 |
| 炼气二层 | 可打 | 打不过 | 打不过 |
| 炼气三层 | 可打 | 仍吃力 | 打不过 |
| 炼气四层 | 可打 | **约可稳赢** | 打不过 |
| 炼气五层 | 可打 | 优势 | 仍吃力 |
| 炼气六层 | 可打 | 优势 | **约可稳赢** |

> 实际战斗受防御、速度、技能、状态（受伤 / 濒死）影响，上表以攻血为主锚点。

## 五、修炼属性（与战斗分离）

闭关、功法经验**不**使用 `BREAKTHROUGH_STAT_*`，仍用原 1.5 / 1.2 / 0.8 灵根与五行系数。详见玩法介绍与 `calcCultivationRate`。

---

## 六、调表指南

1. **妖兽 / 灵兽同级难度**：调 `MONSTER_REALM_COEFFICIENT_BY_KIND`。
2. **人形修士难度**：调 `HUMAN_MONSTER_SPIRIT_ROOT_BY_TIER`、`HUMAN_MONSTER_TIER_STAT_MULTIPLIER`、`getHumanMonsterGongfaLevel` 逻辑。
3. **遇怪分布**：调 `MANGHUANG_MONSTER_KIND_WEIGHTS` 或各地图 `monsterKindRates`。
4. **玩家面板**：调 `BREAKTHROUGH_STAT_*` 或 `realm.ts`；改后重新校验第四节。
5. **引入法器后**：增加法器 contributor，并更新「无功法器」前提。
6. **怪物技能频率**：调 `MONSTER_BATTLE_MP_REGEN_PERCENT`（灵力恢复）或 `skills.json` 中 `cost_mp_percent` / `cooldown`。

---

## 七、怪物战斗灵力恢复

怪物在**自身行动前**按灵力上限比例恢复，配置见 `MONSTER_BATTLE_MP_REGEN_PERCENT`（`combat-balance.ts`）：

| 种类 | 每怪物回合恢复 |
|------|----------------|
| 妖兽 | 50% |
| 灵兽 | 55% |
| 人形 | 35% |

妖兽技能多为「消耗 100% 灵力 + 冷却 2 回合」：大招 → 2 回合普攻攒灵力 → 第 3 回合可再次施放。
